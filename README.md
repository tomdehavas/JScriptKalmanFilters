# JScriptKalmanFilters
This code is supplied as is. This is various demos of Kalman Fiters on web pages sourced from my site https://tomdehavas.com

There is a great deal of material on Kalman filters online but the use of 
different names for the same variables and an approach of understanding the 
method of calculation rather than the calculation can make some of it difficult 
to implement anything from. 

So rather than provide another attempt to explain it without implementing it or 
to implement it without explaining it, I thought I would provide an 
implementation in javascript. Not my first choice of language but easily 
accessible to all.
